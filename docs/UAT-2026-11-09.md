## Fixes made during UAT

- UTM runs its QEMU backend inside `QEMUHelper.xpc`, not as `qemu-system-*`; the scanner now matches `QEMUHelper` too (PRD R3).
- Config/bridge reads and the UTM AppleScript query are applied separately, so a stalled AppleEvent no longer delays names and limits.
- First-tick sample timestamp is taken right before sampling (previously the first CPU/network window was stretched by the 2 s config wait, under-reading by ~30%).
- Interface byte counters come from the per-interface MIB; `NET_RT_IFLIST2`'s `if_data64` wraps at 32 bits on this macOS build.
